Won't connect — what to check

This connects with a direct link to Twitch's own chat servers — no outside library required, so it works the moment the page loads. If a channel still won't connect: double-check the spelling of the username (not display name — the exact login, lowercase, no spaces), confirm the channel exists and isn't banned/suspended, and check that your network doesn't block WebSocket connections (some school/corporate networks do — try a phone hotspot to confirm). Press F12 → Console for the exact error if it keeps failing.

Either way, the Manual chat feed panel further down works with zero connection at all.

Where do I get an avatar proxy URL?

Chat entries work with just a channel name — no login needed. To pull real profile pictures instead of generated avatars, deploy the free, ready-made proxy in avatar-proxy-worker.js (next to this file) to Cloudflare Workers — steps are in a comment at the top of that file, including creating a Twitch app for a Client ID + Client Secret, which live only in the Worker's own settings, never in this page. Paste the *.workers.dev URL it gives you above. The proxy exists because Twitch's own API blocks direct browser requests (CORS) — it can't be called straight from this page.
